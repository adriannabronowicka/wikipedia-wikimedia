# Wikimedia Poland Analytics Dashboard (2001–2026)

## 📌 Project Overview
The goal of this project was to conduct a comprehensive end-to-end analysis of historical digital community growth and readership trends for Wikimedia Poland across a 25-year period (2001–2026). Utilizing multi-source datasets from the Wikimedia Foundation, I focused on transforming raw platform data into a structured, interactive Power BI dashboard that evaluates content expansion, user editor demographics, pageview dynamics, and long-term community engagement.
